# NNN – Niharika News Network Birthday Website

## Open the website
1. Extract this ZIP file.
2. Open `index.html` in Chrome, or upload the complete folder to GitHub Pages / Netlify.
3. Keep the folder structure unchanged.

## Add Niharika's photos
The original photos from the earlier ZIP were not available in this creation session, so photo frames are included with placeholders.
- Put the childhood photo in `assets/` and name it `childhood-photo.jpg`.
- Put the latest photo in `assets/` and name it `latest-photo.jpg`.
- If your photo is PNG, either convert it to JPG or update the matching image filename in `index.html` and `special.html`.

## Add the song manually
- Put the MP3 in `assets/` and name it exactly `niharika-song.mp3`.
- The music player is already included on `special.html`.
- The browser requires the visitor to press Play; autoplay is normally blocked.

## Pages
- `index.html` – Home and headline
- `breaking-news.html` – The four funny news stories
- `special.html` – Photo gallery, Niharika music player, and final wish button

## Customize
All styles are in `assets/style.css`; animations and the final wish button are in `assets/script.js`.
You can edit the birthday wish text in `special.html`.
